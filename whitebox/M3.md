# M3 — derived spike-statistics attention (formalization)

> **Operator name: CRSA — Causal Rate-Statistics Attention** (provisional;
> RRSA "Rate-Reduction Statistics Attention" is the alternate). The
> working name "TSSA" is retired: Decision SpikeFormer (CVPR 2025) owns
> Temporal Spiking Self-Attention, and a 2026 paper uses TSSA for
> Time-Surface Self-Attention. Code accepts the legacy string.
>
> **Prior-art map (targeted search through 2026-08-20):** RetNet shares
> fixed per-head dyadic decays and recurrent/parallel/chunkwise forms —
> closest on implementation choices — but maintains a matrix-valued K^T V
> retention state queried by Q. RWKV/SpikeGPT: constant-state decayed
> recurrence, receptance/key/value weighting, not rate-derived event
> occupancy. Decision SpikeFormer: still pairwise masked QK^T V.
> SpiLiFormer: differential token masking, vision, no causal
> sufficient-statistic recurrence. BiSpikCLM: binary QK dot products with
> explicit attention maps. **The dyadic ladder and chunked scan are NOT
> claimable as novel.** What no prior work combines: learned CRATE
> subspace projections + causal per-subspace event counters + the
> rate-derived marginal price 1/(1+c) + no token pairs or attention
> matrix + K·p-only state + an aligned ΔR^c test showing the trained
> operator retains its derived role + causal-LM quality matching softmax.
>
> **Defensible claim:** *we derive a causal recurrent attention operator
> from rate reduction whose state consists of multiscale subspace-event
> statistics, rather than token-pair similarities.* NOT claimed: first
> recurrent attention, first multiscale decay, first spiking attention,
> first softmax-free causal attention, first TSSA. Final systematic
> literature + patent search still required before any "first."
>
> **Paper-ready statement (M3-control):** *On matched-budget TinyStories,
> the warm-started causal counter operator reached 13.78 perplexity versus
> 14.22 for its softmax parent — a 3.1% improvement — using 384 fixed-state
> counters per layer instead of a sequence-growing KV cache. Its
> conditional coding-rate change remained descent-form throughout
> training, from −5.0 to −11.5.* Robust claim until replicated: CRSA
> matches softmax quality while replacing token-pair attention with
> constant-state causal statistics. Qualifications that keep it
> defensible: one corpus, model scale, and seed; warm-start conversion,
> not yet scratch training; constant-state quality demonstrated within
> the training context; long-distance retention awaiting the
> preregistered probes; ΔR^c agreement is empirical confirmation of the
> predicted sign, not proof that every surrogate step is exact.
>
> **The mechanism comparison (the derivation–execution gap becomes an
> operator-dependent experimental variable):** softmax CRATE — good
> quality, derived substep repurposed; reordered softmax CRATE — better
> quality, more strongly repurposed; counter recurrence — best quality,
> derived descent sign preserved.
>
> **Probe framing:** predictable decay with the dyadic horizons ⇒ an
> honest quality–memory frontier; retention beyond individual half-lives
> via the multiscale population ⇒ a much stronger result; failure ⇒
> 13.78 still establishes an excellent constant-state short-context
> operator — the conclusion narrows, it does not vanish.

Position: replace MSSA's pairwise dense arithmetic with an attention
operator DERIVED from causal spike statistics — not quantized dot-product
attention. Precedent: ToST shows CRATE's coding-rate objective admits
linear-time, non-pairwise attention from projected second moments,
including a causal LM variant; its statistics stay continuous. M3 makes
the statistics event counters and the marginals comparator bits.

This is also the "rate-reduction recurrence" landed safely: the attention
state is a bank of decaying event counters — the same decay-accumulator
structure as the wkv cell we have already synthesized. CRATE×RWKV arrives
via the objective, not via grafting.

## 1. The operator

Auxiliary projected spike code (objective-derived, not an inserted
quantizer — g_spike is the M2 grid-plus-energy penalty, signed variant):

    x_{h,t} = prox_{g_spike}(U_h^T s_t) ∈ {−1,0,1}^p

Causal activity statistic, per head and coordinate:

    c_{h,t} = ρ c_{h,t−1} + x_{h,t}^2        (x^2 is an event BIT)

with dyadic decay ρ = 1 − 2^{−m} implemented as c ← c − (c >> m) + event.
Precision statement: c − ⌊c/2^m⌋ + e equals (1−2^{−m})c + e only when
2^m | c — this is an **integer-exact implementation of the quantized
leaky-counter recurrence**, not real-arithmetic exact decay. If exact
rational decay ever matters, retain the discarded residual bits; the
default is the quantized recurrence, stated as such.

Separable spectral compression objective, f concave nondecreasing (as in
ToST's variational construction):

    R_f(c) = ½ Σ_{h,i} f(c_{h,i}),      marginal price d_{h,t} = f′(c_{h,t})

Compression step and re-quantization:

    s_t ← s_t − η Σ_h U_h (d_{h,t} ⊙ x_{h,t});     s_{t+1} = Q_τ(s_t)

**Hardware-native marginals.** Capped-linear f_κ(c) = min(c, κ) gives
f′ ∈ {0,1}: ONE COMPARATOR BIT per direction — a direction is processed
only while another event still changes its description length. Staircase
f = Σ_r α_r min(c, κ_r) with power-of-two α_r gives shift-weighted
comparator sums. Total operator: counters, comparators, shifts, gated
weight-column additions, the existing prox. No token pairs, no softmax,
no N×N buffer; state is O(K·p) counters.

**Derivation honesty (flagged before a reviewer does).** The compression
step is a **prox-linear frozen-code surrogate**, not a gradient step and
not (absent proof) a majorization: freeze x_ℓ = Q(U^T s_ℓ) as a plug-in
estimate of the projected coordinates, linearize the compression
objective in that code, and take one proximal step. The surrogate is

    R̄(s | s_ℓ) = ⟨ Σ_h U_h (d_h^ℓ ⊙ x_h^ℓ), s − s_ℓ ⟩ + (1/2η)‖s − s_ℓ‖²

whose minimizer, followed by the spike prox, is exactly the proposed
update. "Majorization" would require an upper-bound surrogate touching
the objective at s_ℓ, which we have not proven. The exactness hierarchy:

    M2 spike prox            — exact (proposition, M2.md)
    M3 inhibition/router prox — exact (binary prox, §2)
    M3 compression direction  — frozen-code surrogate, verified
                                empirically by ΔR^c / R(Z) per layer

**FROZEN implementation (validated 2026-08-21, then no further edits):**
chunked parallel scan, **numerically stable and equivalent to the serial
recurrence up to floating-point roundoff** (float32 cumsum is not
bit-exact): rel err vs serial float64 ≤ 6.5×10⁻⁷ at chunk sizes 1, 16,
32, 64; impulse responses match ρ^Δ; future-input perturbations cannot
change earlier outputs; gradients cross chunk boundaries (carry stays
graph-attached — detaching would silently truncate temporal gradients)
and match serial autograd to 1.2×10⁻⁷. Fixed dyadic horizon ladder:

    m   ρ=1−2^−m   exact half-life   mean horizon 1/(1−ρ)
    3   0.875          5.2 tok            8
    4   0.9375        10.7               16
    5   0.96875       21.8               32
    6   0.984375      44.0               64

Multiscale memory without learning ρ: preserves add-and-shift hardware
semantics and keeps horizon learning from confounding the operator test.
M3-control answers ONLY whether the decaying-statistics operator can
replace attention.

**Parallel training form (PSN lemma, arXiv:2304.12760).** The counter is
reset-free, hence a linear temporal filter: c_{h,t} = Σ_{s≤t} ρ^{t−s}
x²_{h,s} — trainable as a causal exponential-kernel convolution in
parallel over the sequence (no per-token loop), with the comparator
marginals applied pointwise. Deployment uses the integer-exact quantized
recurrence, which is NOT a pure linear filter (per-step floor), so
train-parallel vs deploy-quantized drift is measured, not assumed zero.
Sliding-PSN's learnable temporal kernel is the natural ablation if fixed
dyadic decay underperforms on the probe delay grid (spikelm's NeuronTime
— causal depthwise conv initialized to token-shift — is this machinery).

**Causal-LM safety note.** Output magnitude is bounded by design: d is a
bit (or small staircase sum) and x is ternary, so the update magnitude
cannot grow with context length — the normalization-free failure mode of
pairwise unnormalized attention does not apply.

## 2. Pairwise ablation: energy-routed asymmetric spike attention

The strongest compact module from the literature synthesis (A²OS²A's
asymmetric precision + SpiLiFormer's inhibition, both recast as prox):

    q = prox_{g_Q}(U_Q^T s) ∈ {0,1};   k = prox_{g_K}(U_K^T s) ∈ {0..L_K};
    v = prox_{g_V}(U_V^T s) ∈ {−1,0,1}

    r_{tj} = Σ_i q_{ti} k_{ji}                (gated integer accumulation)
    a_{tj} = argmin_{a∈{0,1}} −a·r_{tj} + λ_a·a = 1[r_{tj} > λ_a]
    o_t    = Q_τ(Σ_{j≤t} a_{tj} v_j)          (add/subtract/skip)

The routing mask is an EXACT binary prox: attend to a context only when
its excitation advantage exceeds the event price λ_a — SpiLiFormer's
E−I>θ mechanism, given the objective it didn't state. Asymmetric grids
follow from multiplier-elimination algebra (one discrete operand per
bilinear product suffices), improving on A²OS²A's dense-ReLU K.
Cautions inherited: quadratic in T, needs a score buffer, and published
WTA causal spiking transformers make this an ablation, not the claim.

## 3. Forward-only learning ladder (separate axis — never changed
simultaneously with the operator)

- **U (subspaces)**: Oja rule ΔU_h = η(s x^T − U x x^T) — with ternary
  operands, coincidence-triggered increments/decrements.
- **D (dictionary)**: ΔD = η e a^T — M2b makes both operands discrete
  already: a local ternary Hebbian update.
- **τ (thresholds)**: dual ascent on a firing budget E[1(s≠0)] ≤ ρ*:
  τ ← [τ + η(ρ̂ − ρ*)]_+ — a counter and a homeostatic nudge, replacing
  threshold backprop. (Attention-SNN's multiplicative gates reduce to
  adaptive thresholds τ/m — the additive form is the hardware-native one.)
- **Language signal**, three strictly ordered claims: (1) block-local
  next-token heads, stop-grad between blocks; (2) three-factor local rule
  (pre, post, local error); (3) two-phase forward-only. Terminology care:
  published Forward-Forward transformers keep a local backward op; HBLL
  removes end-to-end backprop but is not purely forward. We claim only
  what the ablation demonstrates.
- **STDP paper**: direction reversed — derive the eligibility trace FROM
  the rate objective, then note the resemblance to STDP. objective →
  plasticity rule, never metaphor → heuristic.

Go/no-go inherits M2's criteria plus stable staircase-bit utilization,
and a memory claim qualified by horizon: with ρ = 1 − 2^{−m} the counter
recurrence has time constant ≈ 2^m tokens (half-life t_½ ≈ ln2·2^m), so
the K·p **attention-operator state** (not total inference memory)
replaces the KV cache by *compressing and forgetting* history, not by
retaining arbitrary context. The comparison set must therefore include:
full-KV attention; sliding-window attention at a MATCHED effective
horizon; RWKV at comparable decay; and several m values, to expose the
quality–memory frontier rather than a single flattering point. The most
revealing functional evaluation is a small order-sensitive suite — copy,
associative recall, induction, varying dependency distance — because it
directly tests what the decaying sufficient statistics preserve (and it
echoes the temporal-task ladder this project already used at circuit
scale in Experiments 1–3).

## 4b. M3-control judgment protocol (agreed pre-launch; four independent axes)

- **Capability**: vs the 14.22 M2-control parent; the 20%/15% relative
  gates carry over (17.06 / 16.35).
- **Temporal function**: copy, recall, dependency-distance across the
  fixed horizon ladder (the locked probe suite).
- **Mechanism**: does the aligned ΔR^c direction remain descent-form, or
  is it repurposed during global LM training? **Explicitly NOT a quality
  gate** — a mechanistic hypothesis under test. M3 can succeed in
  perplexity while falsifying its assigned substep (as M0/M2 did), or
  preserve the descent sign and show that changing the operator changes
  the derivation–execution relationship. Either result is a finding.
- **State health**: counter saturation, dead heads, and utilization
  across m = {3,4,5,6} (measured post-hoc from checkpoints; counters
  recompute from activations).

The single question this isolates: *can causal decaying sufficient
statistics replace token-pair attention while retaining language
capability?*

## 4c. Scaling policy (agreed)

Counter count Kp = d scales WITH width (fixed counters would confound
"more parameters" with "squeezing through the original state"); the
decay ladder m∈{3,4,5,6} is a temporal prior scaled by CONTEXT needs,
never by parameter count — extra coordinates distribute evenly across
horizons. State advantage is width-independent: ~2Td KV values vs ~d
counters ≈ 512× at T=256. Vocabulary-sized counters = a DIFFERENT
mechanism (decayed bag-of-tokens; recurrent lexical memory, honestly
named), not CRSA; progression if identity collisions bite: Kp∝d first,
hashed lexical cache second, vocab bank (shared across layers) last.
Memory-capacity ablation at fixed params (384 vs Kp=d vs wider) deferred.
13.8M scale-up: d=672, L=12, K=8, tied, from scratch (also establishes
scratch trainability, closing a robust-claim qualification); expectation
set BEFORE the run: matched budget ~10-12 (refs: d576 MSSA 12.89, RWKV
6.42 at 14M); levers toward ~6 = budget (20k) then overcomplete
dictionary (4d at d=448 ≈ 14M — the design fork).

**Scale-up qualifications (explicit):** (1) "constant state" = constant
in SEQUENCE LENGTH, not model size — this config holds 672 counters/layer,
8,064 total, at any context. (2) The m={3,4,5,6} ladder is appropriate
while context requirements are unchanged; longer-context scaling must
revisit horizons. (3) The 5,500-step comparison has full standing because
tokens, batch/context, tokenizer, optimizer schedule, and eval protocol
all match the RWKV baseline — not merely update count. Scheduling: the
20k run is a SEPARATE run with its own 20k-horizon cosine (not a
continuation of the 5.5k checkpoint past its schedule); caveat — its
initialization is fresh rather than seed-pinned to the 5.5k run, so the
budget comparison carries init variance. Matched d672 run STOPPED at step 4000 (user call): 17.66 and trailing
the smaller scratch softmax at every checkpoint — the trajectory's
verdict was already legible, and screen throughput matters more than a
completed row. Baseline@3000 for the screens = 19.62. Scale-up observation mid-run: scratch d672 trails scratch d576-MSSA by
~3.4 ppl at matched steps; suspects in order — LR not rescaled with width
(kept 6e-4; μP-style correction ≈ 3.4e-4 — and this family is PROVEN
step-size sensitive), head-count vs head-width allocation (p grew 48→84;
alternative K=14 at p=48), Net2Net width warm-start from d384 M3-control,
the 4d-dictionary fork. LR-corrected run queued as first ablation; the
declared 5.5k/20k pair runs untouched. Outcome map: scratch converges ⇒
warm-start qualification removed; ~10–12 ⇒ width works, gap remains
architectural; plateau at 20k ⇒ overcomplete-dictionary fork; continued
descent toward ~6 ⇒ the gap was substantially budget.

## 5. The claim being assembled

*A causal spike-statistics transformer derived by proximal splitting of a
discrete sparse-rate objective: attention state = event sufficient
statistics (decaying counters — the wkv-cell hardware pattern), attention
coefficients = marginal coding prices (comparator bits), all parameters
admitting local online updates, verified layer-wise by the ΔR^c/R(Z)
diagnostic, and priced post-layout.*

Differentiated from: spiking softmax (quantizes the wrong thing), WTA
attention (pairwise, underived), ToST (continuous statistics), STDP
attention (metaphor-first). Every piece reuses verified infrastructure:
the prox proposition (M2), the collapse diagnostic (M1), the decay
accumulator and counter hardware, and the gate-count pipeline. The
29-LC / 163 MHz serial accumulator is **prior evidence that the datapath
family is cheap and fast — a reusable result, not the M3 hardware
claim**: counter width, K·p replication, projection fanout, and
throughput normalization all await their own synthesis in M3-hardware.
