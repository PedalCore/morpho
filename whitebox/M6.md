# M6 — the synthesis program (formalized 2026-08-26, before any arm runs)

Not "CRATE versus Longhorn." The division of labor, following the
evidence: **Longhorn-family memory for associative retrieval; CRATE's
prox for sparse nonlinear feature coding; counters as the cheap
approximation for heads that only need population statistics; the M2
conversion protocol for every spike rung.**

The distinction that organizes everything:
  counter    c = rho c + k^2          — "how much activity here" (marginal)
  delta      S = A(.)S + (e v) x k^T  — "this key belonged to this value"
Counters are not a bad Longhorn; they are a cheaper MARGINAL
approximation solving a DIFFERENT task. The allocation question is how
much associative state a model actually needs.

## The spiking entry point (spike the OPERANDS, not the state)

Calibrated ternary keys/queries k, q in {-1, 0, +1}^m collapse the
delta memory's expensive ops: k^2 -> binary event mask; ||k||^2 ->
popcount; v x k -> selected add/subtract column writes; S q -> selected
column sums; inactive coordinates neither write nor decay. This maps
far cleaner to hardware than spiking softmax ever did. The state S
STAYS an 8-16 bit accumulator initially (binary state would destroy
accumulated associations).

Conversion ladder (M2 protocol at EVERY rung — calibrate per channel
from float, exact shadow start, ramp, recalibrate on every precision
change, quantizer adjacent to consumer, monitor entropy/occupancy/
retrieval error/extinction; the uncalibrated 4->2->1 schedule is
BANNED — it extinguished representations every time it was tried):
  1 float reference -> 2 ternary q -> 3 ternary q+k ->
  4 sparse/quantized value writes -> 5 fixed-point state ->
  6 (only then) one-bit state / WTA.
Rungs 2-3 run on the synthetic memory suite FIRST.

## The CRATE-Longhorn hybrid (memory stores dictionary codes)

  z = prox_l1(D^T x);  S: k -> z;  x_hat = D (S q)
Interpretable sparse atoms in memory; outer-product writes touch only
active coordinates; codes can drive event-based paths; CRATE supplies
features, Longhorn supplies the retrieval CRATE/CRSA lacked.
STATUS: NOT rejected by the dead-ISTA run — that tested Longhorn with
no functioning feature block. Repair first (below), compare later.

## ISTA calibration repair (gate before any further prox+delta LM run)

Measure pre-prox magnitude against eta*lambda on the dead checkpoint;
calibrate threshold to a target activity distribution; shadow-ramp
identity -> soft threshold. Only then a fair MLP-vs-prox comparison.

## Counter / associative head-allocation sweep (state-matched)

8 heads: 8c/0a | 6c/2a | 4c/4a | 0c/8a (+ block-diagonal S variant,
+ small exact cache variant later). Measure ppl, induction, binding,
update fidelity, state bytes. Hypothesis on record: a SMALL number of
associative heads recovers most capability — many heads only need
recency/frequency statistics.

## Key-incoherence instrumentation (CRATE's geometry applied to
## Longhorn's capacity limit)

Per layer: key Gram off-diagonal energy; effective key rank; collision
rate; pre/post-update retrieval residual; state norm/saturation;
write-strength distribution; retrieval error as facts -> state dim.
FIRST establish whether key collisions predict failures; only then a
light incoherence regularizer / column normalization. NO hard
orthogonality up front (the CRATE autopsy showed global LM training
rejects that premise).

## Forward-only ladder (the original thesis, with a real path now)

Longhorn's fast state already updates forward-only at inference; the
slow weights do not. Ladder: global backprop baseline -> add per-layer
online-retrieval losses -> stop cross-layer gradients through S ->
train each mixer from its local key->value error (feature blocks still
global) -> local sparse-coding losses replace global feature grads.
CRATE contributes the channel-local objective; Longhorn the
sequence-local one.

## Recommended order (locked)

1. Faithful-Longhorn ablation: paper form (x_t target, derived
   forgetting, no W_v, no decay gate) vs our stabilized variant.
2. Instrument the local objective (retrieval residual down; watch key
   collapse and interference).
3. ISTA calibration repair (short health test, no LM run before pass).
4. Ternary q, then ternary q+k (synthetic suite first).
5. Counter/associative mixed-head sweep (smallest binding-retaining
   associative budget).
6. Fixed-point state + hardware costing (delta_cell ladder exists:
   78 gates/element if the learning-rate ladder trains).
7. Only after all that: local/forward-only slow-weight learning.

## The paper-level architecture (the crisp sentence)

*An objective-stacked sequence model in which an online-regression
memory performs retrieval, a sparse-coding prox performs nonlinear
feature expansion, and an energy-priced spike prox makes the memory
operands event-driven* — CRATE's best part without asking compression
to do retrieval; Longhorn's best part without abandoning the white-box
and spiking thesis.
