# M2 — spike-driven weight paths in causal CRATE

Formalized before training, per protocol. Positioning (exact words we will
defend): *an objective-derived, spike-driven weight-path language model with
layerwise diagnostics and post-layout hardware evaluation.* Not "purely
spiking": attention arithmetic (scores, weighted sums) and the residual
additions remain dense float.

## 1. The spike operator is a proximal operator — exactly

**Proposition.** Let `G = {0, thr, 2·thr, …, L·thr}` and define the penalty
`g(a) = (thr/2)·a + ι_G(a)` (a *linear per-spike energy cost* plus the grid
constraint). Then for almost every `v`:

```
prox_g(v) = argmin_{a∈G} ½(a−v)² + (thr/2)·a
          = thr · clamp(floor(v/thr), 0, L)
```

*Proof.* Candidates are grid points. For interior neighbors `k·thr` vs
`(k+1)·thr` with `v ∈ (k·thr, (k+1)·thr)`, the quadratic-cost difference is
`½·thr·(2v − (2k+1)·thr)` and the penalty difference is `(thr/2)·thr`;
`(k+1)` wins iff `v > (k+1)·thr` — never inside the interval, so the floor
point always wins. The clamp is the box part of `G`. ∎

Consequence for the derivation: the ISTA block's soft-threshold (prox of
λ‖·‖₁ + nonnegativity) is replaced by the prox of an **energy-metered
sparsity penalty**. The alternating scheme — compression step, then prox
step — is unchanged; only the penalty changed, and the penalty is the
hardware's own cost model. Trained per-channel thresholds generalize `g`
per channel (the fixed-cost `λ·1[a≠0]` variant shifts only the 0→thr
boundary and is absorbed by training `thr`; noted, not claimed).

Prior art honesty: prox-based quantized training exists (ProxQuant);
spiking causal LMs claiming matmul-free paths exist (WTA-ST, BiSpikCLM).
The narrow claim: *this prox as the sparse-coding step of a white-box
derived architecture, with the derivation's own diagnostics carried
through training and the datapath priced post-layout.*

## 2. Block equations

Layer state is a **code vector** `z_ℓ ∈ G^d` at every block boundary
(block 0: `z₀ = prox(LN(emb + pos))`). Per block:

```
h_k  = U_k z_ℓ                      # U consumes CODES — no LN in between
att  = scale · U^T [SSA_k(h)]_k     # attention arithmetic dense (declared)
x    = z_ℓ + att                    # residual, float
u    = LN(x)
r    = u − D z_ℓ                    # reconstruction error; D consumes CODES
r̃    = sprox(r)      [M2b only]    # ternary error codes: sign·clamp(floor(|r|/thr_e),0,L)·thr_e
v    = z_ℓ + η · D^T r̃             # D^T consumes ternary CODES (M2b) or float r (M2a)
z_ℓ+1 = prox(v)                     # the energy-metered spike prox
```

Final: `logits = W_head · z_L` — the head consumes codes directly (the
final LayerNorm is dropped; the head's rows absorb scale). Per-channel
thresholds fold into every consumer's weight columns offline, so integer
consumption survives trained thresholds.

The ISTA change from CRATE eq. 17 is the unroll point: CRATE initializes
the code at the signal (`a₀ = u`); M2 initializes at the *previous layer's
code* (`a₀ = z_ℓ`), which is the standard ISTA iteration on the code
sequence and is what lets D act on codes. M2b additionally quantizes the
error — a prox-compressed gradient step (relation to error-feedback /
quantized-gradient methods stated, not oversold).

## 3. Coverage accounting (d=384, L=12, measured shares)

Weight-path MACs per token: 12 blocks × (U d² + D d² + Dᵀ d²) = 5.31M,
head 1.57M, total 6.88M.

| variant | consumes codes | share |
|---|---|---|
| M1 (shipped) | nothing (LN re-densifies) | 0% |
| M2a | U, D, head | 74% |
| M2b | U, D, Dᵀ (ternary errors), head | **100% of weight-path** |

The go/no-go bar (≥80%) is met only by M2b; M2a is the ablation rung that
separates "codes into consumers" from "quantized error propagation."

## 5. Go/no-go criteria (agreed)

- initial go: within 20% relative ppl of M0 (≤18.4); paper target ≤17.7
- ALSO reported against the true float parent M2-control (14.22, which
  BEAT M0): 20% = 17.06, 15% = 16.35 — a model at 18.0 passes the
  preregistered gate while sitting 27% behind its actual parent; both
  numbers are stated wherever either is
- R(Z) stays inside the fluent M0/M1 envelope through depth (no crash)
- ≥80% of weight-bearing activation paths consume integer codes (M2b: 100%)
- nonzero threshold gradients in every instrumented layer
- post-layout advantage after control overhead (zero-detect, routing,
  accumulation, buffering, throughput-normalized) — not nominal multiply
  counts
- stable spike rate, **code entropy**, and code magnitude across depth —
  "mostly zero" alone is not success

## 5b. Findings during the ladder (amendments logged, protocol unchanged)

**The derivation–execution gap (autopsied, and larger than first thought).**
Named claim: *deriving a layer from an objective does not guarantee that
end-to-end training leaves the learned layer executing that objective.*
Under the aligned substep evaluation, M2-control's attention EXPANDS R^c
in 12/12 layers (mean +54) while being the best float model (14.22).
The full autopsy (`autopsy.py`: directional derivative, α-sweep, complete
objective, basis orthonormality) then overturned the reference point:
**M0 — the derivation-faithful wiring — does the same thing.** Its
earlier "compression" reading was an artifact of the misaligned (LN'd)
logging convention. Aligned, both models show:

- g_dir = ⟨∇R^c, δ⟩ > 0 in 12/12 layers (both) — genuine ascent
  directions, not overshoot (every α in the sweep expands, 12/12 both);
- Δ(R − R^c) > 0 in 12/12 (M2 mean +37.3, M0 +5.4): attention INCREASES
  the complete rate-reduction objective while violating its assigned
  compression sub-role — the "abandoned role, helps the broader
  geometry" branch of the taxonomy, in both wirings;
- per-head ‖W_k W_kᵀ − I_p‖_F ≈ 5.6 (M0) / 12.0 (M2) against ‖I_p‖_F ≈
  6.9 — the subspace-basis assumption is substantially violated in both,
  roughly doubly so after the reorder.

**Paper-level claim (agreed wording):** *In both derivation-faithful and
reordered CRATE, global language-model training learns attention updates
that ascend the assigned conditional coding-rate term while improving
the broader R − R^c geometry. White-box derivation therefore supplies a
falsifiable mechanistic hypothesis, not a guarantee about the trained
computation.* Causal scope, stated carefully: the evidence implicates
**global end-to-end LM optimization, not backpropagation itself** —
backprop on a local R^c objective should preserve the assigned role,
and a forward-only estimator of the global objective could still
repurpose it. All pre-autopsy logged ΔR^c values used the superseded
LN'd convention and are labeled as such.

**Gram decomposition (run before claiming the premise fails):** per-head
E_diag / E_off / normalized-column E_off vs ‖I_p‖_F = 6.93 —
M0: 3.36 / 4.08 / **7.40**, sv range [0.36, 1.75];
M2-control: 1.88 / 11.79 / **11.47**, sv range [0.36, 3.02].
The normalized off-diagonal error dominates in both: the learned
directions genuinely ceased to form orthogonal subspace bases — a
directional failure, not a scale drift absorbable into step sizes.

**Gap-attribution control ladder (the minimal set that can assign
cause; M3-local alone cannot, since it changes objective, credit scope,
and update rule at once):**

| arm | change | closes the gap ⇒ |
|---|---|---|
| Global-BP | current baseline | (reference) |
| Local-loss BP | ordinary gradients, each block optimizes its assigned local R^c objective, stop-grad at block boundaries | global credit assignment caused the repurposing |
| Constrained global-BP | end-to-end LM loss + orthogonality and local-objective constraints | task optimization and derivation coexist when premises are enforced |
| Local rules | Oja/Hebbian/homeostatic | the update dynamics themselves matter |
| Block-local prediction | no cross-layer gradients | — |

If none closes it without unacceptable perplexity: objective
faithfulness has a measurable capability cost — itself a headline
number.

**M2-spike's failure classifies as calibration, not impossibility.**
96% sparsity at step 0 = the warm-started activations landed almost
entirely in the quantizer's dead zone (distribution–grid mismatch); the
optimizer must revive activity and repair every consumer at once.
Diagnostics at step 3000: thresholds all training; code entropy healthy
(1.3–1.7 bits); R(Z) depressed 452→259 vs the control envelope 576→493;
error codes near-dense (72–90%).

**Designated rescue arm (runs only if the annealed arm also fails):
calibrated conversion** — start from the M2-CONTROL checkpoint (the true
parent), set per-layer/channel thresholds from measured pre-consumer
activation quantiles to match the fluent M1 firing envelope with rare
saturation, ramp a float→quantized blend x̃ = (1−α)x + αQ(x) with α: 0→1,
finish on the exact hard prox, and only then coarsen precision toward the
target grid. Implemented: `calibrate.py`, `--calibrate-from`,
`--blend-steps`. Log-based mechanism triage: dead-zone trapping =
near-zero thr grads + near-zero entropy; grid too coarse = healthy grads,
low entropy; consumer information loss = restored activity, poor ppl;
layerwise calibration needed = early-layer silence with late recovery.
